# Trust Fracture

**Estado: en construcción.** Todavía no existe código funcional. Este
repositorio contiene por ahora solo el registro de decisión arquitectónica
y el plan de construcción.

Trust Fracture es una herramienta de investigación basada en grafos para
violaciones de fronteras de confianza en sistemas de agentes de IA: ayuda a
determinar si, y cómo, una entrada sin autoridad puede llegar a influir
sobre una operación privilegiada, usando un grafo persistido en
[Relate](https://relatedb.ai) y una distinción explícita y honesta entre
hecho estructural, posibilidad estructural, comportamiento observado,
violación de política verificada y evidencia insuficiente.

Ver `docs/decisions/ADR-001-language-selection.md` para la decisión de
lenguaje y `docs/LEVELS.md` para el plan de construcción.

Nada debajo de esta línea está implementado todavía.
