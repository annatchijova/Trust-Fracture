# Trust Fracture

**Status: under construction.** No functional code exists yet. This
repository currently contains only the architectural decision record and
the build plan.

Trust Fracture is a graph-based investigation tool for trust-boundary
violations in AI agent systems: it helps determine whether, and how, an
untrusted input could gain influence over a privileged operation, using a
graph persisted in [Relate](https://relatedb.ai) and an explicit,
honest distinction between structural fact, structural possibility,
observed behavior, verified policy violation, and insufficient evidence.

See `docs/decisions/ADR-001-language-selection.md` for the language
decision and `docs/LEVELS.md` for the build plan.

Nothing below this line is implemented yet.
